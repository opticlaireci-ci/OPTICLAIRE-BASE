# Règlements — Tous les modes de paiement

La visualisation **PDF & EXCEL** du rapport « Règlements » / « Mouvements financiers » utilise maintenant l'option **« Tous les modes de paiement »** par défaut.

Quand cette option est sélectionnée, le rapport inclut :
- les règlements enregistrés (espèces, carte, virement, chèque, etc.) ;
- les acomptes ;
- les bons d'assurance présents sur les ventes, avec leur montant de prise en charge ;
- l'assurance et le numéro de bon dans les détails du règlement.

Le total encaissé inclut également les montants des bons d'assurance.
